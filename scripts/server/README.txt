Hearth & Hollow server

1. Install Java 21.
2. Read the Minecraft EULA (https://aka.ms/MinecraftEULA) and, if you agree, create eula.txt containing: eula=true
3. Run start.sh (Linux/macOS) or start.bat (Windows). The first run installs NeoForge.

Full guide: https://github.com/cosmicspork/hearth-and-hollow/blob/main/docs/server.md
